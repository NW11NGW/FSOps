PLEASE READ BEFORE "OPTIMISING" THESE FILES
-------------------------------------------

These are shipped verbatim and parsed at runtime on purpose. Gzip is a compression
container, not a modification, so the bytes above round-trip exactly and what FSOps
distributes is still the published file.

It would be faster to pre-process them into a trimmed, FSOps-shaped index at build time.
Do not. CC BY-SA 4.0 is a share-alike licence: a derived database built from this data
would itself have to be released under CC BY-SA, which would pull the obligation inward
from "two clearly third-party files in a data folder" to "a file FSOps generates and
ships as part of itself". Redistributing the originals with attribution carries no such
consequence. The parsing cost this avoids is a few hundred milliseconds, once, lazily,
on the first request that needs a boundary.

To update to a newer AIRAC cycle: download both files from the repository above, gzip
them into this folder under the same names, and update the hashes and date here.
